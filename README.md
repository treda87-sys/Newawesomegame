# Newawesomegame (Unity Starter)

Dies ist das Unity‑Starter-Template für Newawesomegame.

Inhalt:
- .gitignore: Standard Unity-Ignore-Datei.
- LICENSE: MIT.
- Assets/Scripts/PlayerController.cs: Platformer 2D PlayerController mit Coyote Time und Jump Buffer.
- Assets/Scripts/CameraFollow.cs: einfacher sanfter 2D Kamera-Follow.
- Assets/Scripts/EnemyPatrol.cs: einfacher Patrouillen-Enemy.

Kurz: Erstelle lokal ein Unity‑Projekt (2D, Unity 2022.3 LTS), füge die Ordner/Dateien aus diesem Repo in dein Projektverzeichnis ein und öffne das Projekt in Unity.

Schnelle lokale Installation (falls du selbst pushen willst):
1. Erstelle ein neues Unity‑Projekt (2D recommended).
2. Lege die Ordner Assets/Scripts/ im Projektordner an.
3. Kopiere die untenstehenden Dateien in dein Projekt.
4. Git:
   git checkout -b unity-starter
   git add .
   git commit -m "Add Unity starter files"
   git push --set-upstream origin unity-starter

How I proceeded: I am pushing these files into branch unity-starter so you can check them out in Unity.
